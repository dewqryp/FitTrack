# FitTrack

Учебный проект для управления тренировками и прогрессом пользователей.

## Планируемый стек

- Java 21
- Spring Boot
- PostgreSQL
- React
- REST Assured
- Docker
- GitHub Actions

## Структура

- `backend` — REST API
- `aqa` — автоматизированные API-тесты
- `frontend` — пользовательский интерфейс
- `docs` — документация проекта
